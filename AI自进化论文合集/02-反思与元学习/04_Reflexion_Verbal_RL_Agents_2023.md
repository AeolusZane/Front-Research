# Reflexion：语言智能体的语言强化学习（Reflexion: Language Agents with Verbal Reinforcement Learning）

> arXiv: 2303.11366 ｜ Noah Shinn, Federico Cassano 等 / Northeastern University, MIT, Princeton University ｜ 2023

## 摘要（全文翻译）

大语言模型（LLMs）被越来越多地用于与外部环境（如游戏、编译器、API）交互，以驱动目标导向型智能体。然而，与传统强化学习方法相比，这些语言智能体难以通过试错快速高效地学习——传统强化学习需要大量训练样本和昂贵的模型微调。本文提出 Reflexion，一种**不通过权重更新、而是借助语言反馈**来强化语言智能体的新型框架。具体而言，Reflexion 智能体对任务反馈信号进行语言层面的反思，并将自我反思的文本保存在情节记忆缓冲区中，以便在后续尝试中做出更优的决策。Reflexion 足够灵活，可以融合多种类型（标量值或自由格式语言）和多种来源（外部或内部模拟）的反馈信号，并在多种任务（序列决策、编程、语言推理）中，相比基线智能体取得了显著改进。例如，Reflexion 在 HumanEval 代码生成基准上实现了 91% 的 pass@1 准确率，超越了此前最优的 GPT-4（80%）。我们还对不同反馈信号、反馈融合方法及智能体类型进行了消融与分析研究，揭示了它们对性能的影响。所有代码、演示和数据集均已在 https://github.com/noahshinn024/reflexion 开源。

## 背景与动机

基于 LLM 的自主智能体（如 ReAct、SayCan 等）已展现出强大的决策能力，但由于模型参数量巨大，传统的梯度下降强化学习方法对其来说计算成本极高，通常只能依赖上下文少样本示例作为唯一的"学习"手段。这意味着智能体在反复试错时无法真正从失败中积累经验——每次尝试都是"重新开始"。

Reflexion 的出发点在于：**将环境反馈信号转化为语言形式的"梯度"**。语言反馈比标量奖励更为丰富，能为智能体提供具体、有针对性的改进方向，类似于人类反思自身失败经历并制定更优行动计划的过程。

## 方法（核心机制）

Reflexion 由三个独立模块协同工作：

### 三角色架构

- **演员（Actor，Ma）**：基于 LLM，生成文本和动作序列（可采用 CoT 或 ReAct 策略）。演员维护一个记忆组件 mem，记录当前轨迹（短期记忆）和历史反思（长期记忆）。
- **评估器（Evaluator，Me）**：对演员产生的轨迹评分，生成奖励信号。针对不同任务灵活定义：推理任务用精确匹配，决策任务用启发式函数或 LLM 分类，编程任务用自生成的单元测试。
- **自我反思模型（Self-Reflection，Msr）**：同样是 LLM，接收稀疏奖励信号（如二元的成功/失败）、当前轨迹和历史记忆 mem，生成细粒度的语言反馈 srt。该反馈随后被存入 mem，供下一轮尝试使用。

### 迭代优化流程

1. 演员执行任务，产生轨迹 τ；
2. 评估器打分，产生奖励 r；
3. 自我反思模型基于 {τ, r} 生成语言经验总结 sr，追加到记忆 mem；
4. 演员在下一轮以更新后的 mem（含历史反思）为上下文重新尝试；
5. 重复直至评估器判定成功，或达到最大尝试次数。

记忆窗口 Ω 通常设为 1–3 条，以不超出 LLM 的上下文限制。

### 反馈信号多样性

- **决策任务（AlfWorld）**：使用启发式检测（如重复动作超过3次、步数超过30步即触发自我反思）或 LLM 二元分类作为评估信号。
- **推理任务（HotPotQA）**：使用精确匹配评分，CoT 或 ReAct 生成，反思后重试。
- **编程任务（HumanEval/MBPP）**：先用 CoT 生成自测试用例集（经 AST 验证语法），再依据测试结果进行自我反思，支持 pass@1 报告。

## 实验与结论

**主要实验设置：**
- 决策：AlfWorld 134个文本游戏环境，6类任务；
- 推理：HotPotQA 100个多跳问题；
- 编程：HumanEval（Python/Rust）、MBPP（Python/Rust）、LeetcodeHardGym（40道困难题）。

**关键数值结果：**

| 任务 | 基线 | Reflexion | 提升 |
|---|---|---|---|
| AlfWorld（12次迭代）| ~68% | 130/134（97%）| +22%（绝对值）|
| HotPotQA ReAct | ~30% | ~51% | +20%（绝对值）|
| HumanEval Python | 80.1%（GPT-4）| **91.0%** | +11% |
| HumanEval Rust | 60.0%（GPT-4）| 68.0% | +8% |
| LeetcodeHard Python | 7.5%（GPT-4）| **15.0%** | +7.5% |

**消融实验（HumanEval Rust 50题）：**
- 去除自生成测试：52%（低于基线 60%），证明单元测试对于识别错误不可或缺；
- 去除自我反思（仅保留测试反馈）：60%，与基线持平，证明反思步骤才是改进的来源；
- 完整 Reflexion：68%，两者缺一不可。

**分析与局限：**
- Reflexion 的自我反思能力是**大模型的涌现特性**，在规模较小的模型（如 starchat-beta）上几乎没有效果；
- 在 WebShop 电商搜索任务上，Reflexion 无法显著超越基线——当任务需要大量多样性探索和精确的自然语言搜索时，语言反思面临局限；
- 本质上，Reflexion 是一种基于自然语言的策略优化，仍可能陷入局部最优；
- 长期记忆仅为滑动窗口，未来可扩展为向量数据库或 SQL 结构。
