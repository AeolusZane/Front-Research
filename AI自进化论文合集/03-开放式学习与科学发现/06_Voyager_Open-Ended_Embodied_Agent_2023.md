# VOYAGER：基于大型语言模型的开放世界具身终身学习智能体（VOYAGER: An Open-Ended Embodied Agent with Large Language Models）

> arXiv: 2305.16291 ｜ Guanzhi Wang, Yuqi Xie, Yunfan Jiang, Ajay Mandlekar 等（NVIDIA、加州理工、UT Austin、Stanford、UW Madison） ｜ 2023

## 摘要（全文翻译）

我们介绍 VOYAGER，首个由大型语言模型驱动的 Minecraft 具身终身学习智能体，它能够持续探索世界、习得多样技能并在无人干预的情况下做出新发现。VOYAGER 由三个关键组件构成：1）一个最大化探索的自动课程（automatic curriculum）；2）一个不断增长的可执行代码技能库（skill library），用于存储和检索复杂行为；3）一种新颖的迭代提示机制（iterative prompting mechanism），整合环境反馈、执行错误和自我验证来持续改进程序。VOYAGER 通过黑盒查询的方式与 GPT-4 交互，无需访问模型参数或进行参数微调。VOYAGER 所开发的技能具有时间延展性、可解释性和组合性，能够迅速复合提升智能体的能力，并缓解其他持续学习方法中常见的灾难性遗忘问题。在实证上，VOYAGER 展现出强大的上下文终身学习能力，在 Minecraft 游戏中表现出色：与现有最先进方法相比，它能获得 3.3 倍以上的独特物品、行进 2.3 倍以上的距离，并以快达 15.3 倍的速度解锁关键科技树里程碑。VOYAGER 能够利用在一个 Minecraft 世界中学得的技能库，在全新世界中从零开始解决新任务，而其他方法则难以做到这样的泛化。

## 背景与动机

构建能在开放世界中持续探索、规划并积累新技能的通用具身智能体，是 AI 领域的核心挑战之一。经典方法（强化学习、模仿学习）基于原始动作操作，在系统性探索、可解释性和泛化方面存在天然局限。基于 LLM 的智能体虽借助预训练世界知识生成行动计划，但它们并非**终身学习者**（lifelong learner）——缺乏跨时间跨任务地持续获取、更新、积累和迁移知识的能力。

作者选择 Minecraft 作为实验平台。Minecraft 没有预设终点，提供了广阔的开放探索空间：玩家须在程序生成的 3D 地形中探索，利用采集的资源解锁科技树，从砍木、做工具，到冶炼、对抗怪物，技能层层递进。这要求智能体能够：（1）基于当前技能水平和世界状态提出合适任务；（2）根据环境反馈精炼技能并将掌握的技能记忆以备复用；（3）以自驱方式持续探索并寻找新任务。

## 方法（核心机制）

VOYAGER 由三个核心模块构成，相互协同形成终身学习飞轮。

### 1. 自动课程（Automatic Curriculum）

自动课程利用 GPT-4 丰富的互联网知识，持续为智能体提出下一个合适的探索任务。课程以**自底向上**（bottom-up）方式展开，结合探索进度和智能体当前状态动态调整任务难度。GPT-4 的输入提示包含：
- 多样化行为指令（"尽可能发现更多不同的东西……下一个任务不能太难……"）；
- 智能体当前状态（背包、装备、附近方块与实体、生物群系、时间、生命值、饥饿值、坐标）；
- 已完成和失败的任务列表（反映探索进度与能力边界）；
- 通过 GPT-3.5 的自问自答额外背景（GPT-3.5 用于标准 NLP 任务以节约预算）。

总体目标为 "发现尽可能多的不同事物"，可视为一种**上下文内新颖性搜索**（in-context novelty search）。

### 2. 技能库（Skill Library）

技能以**可执行代码**表示，每段代码封装完成特定任务所需的一系列动作（如 `craftStoneShovel()`、`combatZombieWithSword()`）。这样的代码化技能具备：
- **时间延展性**：单个函数覆盖多步操作；
- **可组合性**：复杂技能通过复用更简单的技能函数构建；
- **可解释性**：代码可供人读懂并调试。

**技能添加**：每当 GPT-4 生成并通过验证的新技能，将其代码及其 GPT-3.5 生成的描述嵌入向量（embedding）一起存入向量数据库，key 为描述的嵌入向量，value 为代码本体。

**技能检索**：面对新任务时，先用 GPT-3.5 生成解题建议，结合环境反馈作为查询，检索前 5 个最相关技能，注入 GPT-4 的上下文以支持代码生成。

### 3. 迭代提示机制（Iterative Prompting Mechanism）

LLM 难以一次性生成正确的动作代码，因此引入三类反馈的迭代优化循环：

1. **环境反馈（Environment Feedback）**：程序执行中途的进度信息，例如"我需要 2 块木板才能制作木棍"，直接揭示失败原因；
2. **执行错误（Execution Errors）**：代码解释器报告的语法错误或非法操作（例如试图合成 Minecraft 中不存在的"金合欢斧"，应改为木斧），用于程序调试；
3. **自我验证（Self-Verification）**：另起一个 GPT-4 智能体作为批评者——给定当前状态和任务描述，判断程序是否成功完成任务，若失败则提供改进建议。这比单纯的自我反思更全面，同时检查成功与归因失败。

每轮代码生成后，执行程序并获得环境反馈与执行错误，将其并入 GPT-4 提示词发起下一轮精炼，直至自我验证模块确认任务完成，将新技能提交至技能库，并向自动课程请求下一个目标。若连续 4 轮失败，则请求新任务。

## 实验与结论

### 实验设置

- **模型**：GPT-4（`gpt-4-0314`）用于代码生成与自我验证，GPT-3.5-Turbo（`gpt-3.5-turbo-0301`）用于自问自答和嵌入生成（`text-embedding-ada-002`）；
- **环境**：MineDojo（开源 Minecraft AI 框架）+ Mineflayer JavaScript API 控制底层动作；
- **温度参数**：代码生成 0，自动课程 0.1（增加任务多样性）。

### 对比基线

- **ReAct**：思维链提示 + 动作计划交替；
- **Reflexion**：ReAct + 自我反思；
- **AutoGPT**：GPT-4 任务分解 + ReAct 循环，无技能库、无自我验证、无自动课程。

### 关键实验结果

**探索能力（Exploration）**  
160 次提示迭代内，VOYAGER 发现 63 种独特物品，是对比基线最优值的 **3.3 倍**。ReAct 和 Reflexion 几乎无法推进，AutoGPT 发现物品数量明显落后。

**科技树掌握（Tech Tree Mastery）**  
Minecraft 科技树：木工具 → 石工具 → 铁工具 → 钻石工具。VOYAGER 解锁木工具比基线快 **15.3 倍**，石工具快 **8.5 倍**，铁工具快 **6.4 倍**，且是**唯一**解锁钻石级别的方法（3 次中 1 次成功），而所有基线方法均未能达到钻石级别。

**地图覆盖（Map Coverage）**  
VOYAGER 探索的距离是基线的 **2.3 倍**，能穿越多样地形；基线智能体往往被困在局部区域。

**零样本泛化（Zero-Shot Generalization）**  
将智能体背包清空、置入全新世界、测试 4 个未见任务（钻石镐、金剑、岩浆桶、指南针）。在最多 50 次提示迭代内：
- ReAct、Reflexion、AutoGPT 全部 0 成功（0/3 次）；
- AutoGPT + VOYAGER 技能库：仅部分任务达到 1–2/3；
- VOYAGER（无技能库）：多任务 2–3/3 但迭代更多；
- VOYAGER（完整）：4 个任务**全部 3/3 成功**，平均仅需 18–21 次迭代。

这充分证明技能库是可迁移的 plug-and-play 资产，而不是过拟合于特定世界。

### 结论与局限

VOYAGER 展示了一条无需参数微调、仅靠提示词工程即可实现具身终身学习的可行路径，三大组件缺一不可。局限在于：完全依赖 GPT-4 API（高成本、黑盒）；仅测试于 Minecraft 文本接口（高层 API）而非像素级控制；技能库随任务增多是否会出现检索质量下降有待深入研究。
