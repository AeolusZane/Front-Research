# 智能体系统的自动化设计（Automated Design of Agentic Systems）

> arXiv: 2408.08435 ｜ Shengran Hu, Cong Lu, Jeff Clune（英属哥伦比亚大学 / Vector Institute / Canada CIFAR AI Chair）｜ 2024（ICLR 2025 会议论文）

## 摘要（全文翻译）

研究人员正在投入大量精力开发强大的通用智能体，其中基础模型（Foundation Models）被用作智能体系统中的模块（如思维链、自我反思、Toolformer）。然而，机器学习的历史告诉我们，手工设计的解决方案最终会被学习得到的解决方案所取代。我们描述了一个新兴研究领域——智能体系统自动化设计（ADAS，Automated Design of Agentic Systems），其目标是自动创建强大的智能体系统设计，包括发明新颖的构建模块和/或以新方式组合它们。我们进一步证明，在 ADAS 中存在一种尚未充分探索但颇具前景的方法：智能体可以用代码来定义，新的智能体可以由一个元智能体（meta agent）通过编写越来越好的代码来自动发现。由于大多数编程语言都是图灵完备（Turing Complete）的，这种方法在理论上能够学习任何可能的智能体系统，包括新颖的提示、工具使用、工作流程以及它们的各种组合。我们提出了一个简单而有效的算法——元智能体搜索（Meta Agent Search），以演示这一思想：元智能体基于一个不断增长的历史发现档案，迭代地编写有趣的新智能体。通过在编程、科学和数学等多个领域的广泛实验，我们表明该算法能够逐步发明具有新颖设计的智能体，其性能大幅超越最先进的人工设计智能体。重要的是，我们持续观察到一个令人惊喜的结果：Meta Agent Search 发明的智能体在跨领域和跨模型迁移时仍保持优越性能，证明了其鲁棒性和通用性。若能安全地开发这一方向，我们的工作揭示了一个令人振奋的新研究方向的潜力——朝着自动设计愈发强大的智能体系统迈进，以造福人类。所有代码已在 https://github.com/ShengranHu/ADAS 开源。

## 背景与动机

**问题背景**：大型基础模型（如 GPT、Claude）正被广泛用作通用智能体，但可靠地解决复杂问题往往需要由多个组件构成的复合智能体系统，而非单次模型查询。研究人员已手工设计了大量构建模块：思维链规划与推理（Chain-of-Thought）、记忆结构、工具使用、自我反思等，但将这些模块组合成复杂系统通常需要大量的领域特定人工调优。

**核心洞察**：机器学习历史表明，手工设计的方案终将被学习得到的方案取代——从 HOG 特征到 CNN，从手工 AutoML 到神经架构搜索，均遵循此规律。因此，提出核心问题：**能否自动化设计智能体系统？**

**现有局限**：现有大多数自动化尝试仅聚焦于优化提示词（Prompt），极大地限制了其发现灵活设计模式的能力。本文提出在代码空间中搜索整个智能体系统，理论上可表示任何可能的构建模块组合。

## 方法（核心机制）

### ADAS 形式化框架

ADAS 被形式化为一个优化过程，包含三个关键组件：

- **搜索空间（Search Space）**：决定哪些智能体系统可以被表示和发现。本文采用 Python 代码作为搜索空间——由于 Python 是图灵完备的，理论上能表示任何可能的智能体系统，包括所有提示、工具使用、工作流程等组件。
- **搜索算法（Search Algorithm）**：如何在搜索空间中探索。本文以大型基础模型作为元智能体，迭代生成新的智能体代码。
- **评估函数（Evaluation Function）**：如何评估候选智能体，例如在目标领域验证集上的准确率。

### Meta Agent Search 算法

核心流程如下：

1. **初始化档案**：可选地用已有基准智能体（如 Chain-of-Thought、Self-Refine）初始化档案。
2. **设计新智能体**：元智能体（使用 GPT-4）以档案为条件，生成一个高层次创意描述，再将其实现为代码。新设计经过两步自我反思（Self-Reflection）以确保新颖性。
3. **评估与修复**：生成的智能体在目标领域验证数据上评估；若运行出错，元智能体执行自我反思并修正，最多重试 5 次。
4. **更新档案**：将智能体连同评估指标加入档案，然后继续下一轮迭代，直到达到最大迭代次数。

**关键设计**：元智能体被鼓励探索"有趣"（novel or worthwhile）的新智能体，并以一个仅约 100 行代码的简洁框架为基础，只需编写一个 `forward` 函数来定义新智能体系统，类似 FunSearch 的做法。

## 实验与结论

### 实验设置

- **元智能体**：GPT-4；**被评估智能体**：GPT-3.5（降低成本）
- **测试基准**：
  - ARC 挑战（抽象与推理语料库，用于测试 AI 通用智能）
  - DROP（阅读理解）
  - MGSM（多语言数学）
  - MMLU（多任务问题解决）
  - GPQA（研究生级别科学问题）
- **基准方法**：Chain-of-Thought（CoT）、COT-SC、Self-Refine、LLM Debate、Step-back Abstraction、Quality-Diversity、Role Assignment、OPRO（提示优化）

### 关键结果

**ARC 挑战**：Meta Agent Search 逐步发现了显著优于所有基准的智能体。最佳发现的智能体采用了复杂的反馈机制：5个思维链并行生成答案 → 多类型专家（效率专家、可读性专家、简洁性专家）提供反馈 → 精炼3次 → 集成取最终答案。

**多领域推理**（表1）：

| 领域 | 最佳基准（Role Assignment） | Meta Agent Search | 提升 |
|---|---|---|---|
| 阅读理解（F1） | 65.8 | **79.4** | +13.6 |
| 数学准确率（%） | 39.0 | **53.4** | +14.4 |
| 多任务准确率（%） | 65.9 | **69.6** | +3.7 |
| 科学准确率（%） | 31.6 | **34.6** | +3.0 |

**跨域迁移**：将数学领域（MGSM）发现的智能体迁移至其他领域：
- GSM8K 准确率：最佳基准 43.6% → 搜索智能体 **69.5%**（提升 25.9%）
- GSM-Hard 准确率：最佳基准 18.0% → 搜索智能体 **31.2%**（提升 13.2%）
- 甚至在非数学领域（阅读理解、多任务）也优于手工基准

**跨模型迁移**：在 ARC 上，将 GPT-3.5 上搜索的智能体迁移至 Claude-Sonnet，最佳智能体（Dynamic Memory and Refinement Agent）达到 **48.3%** 准确率，远超 Claude-Sonnet 上的人工设计基准（39.3%，Self-Refine）。

### 主要结论与局限

- ADAS 中的代码空间搜索优于提示优化方法（OPRO 等），验证了全组件学习的优势。
- 发现的设计模式遵循"进化式"积累：先有基础创意（迭代3），后续发现在此基础上逐步叠加（类似交叉重组）。
- **局限**：当前仅评估单步 QA 任务；当 FM 自身知识不足时（科学、多任务领域），优化智能体系统的收益有限；代码执行存在安全风险，需容器化隔离。
- **未来方向**：高阶 ADAS（元智能体本身也可被 ADAS 改进）、在线持续学习、多目标 ADAS（同时优化性能、成本、延迟）。
